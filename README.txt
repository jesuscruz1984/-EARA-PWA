EARA AI PWA — iPhone test prototype

FASTEST FREE WAY TO USE IT
1. Upload the contents of this folder to any free HTTPS static host.
   Easy options: GitHub Pages, Netlify Drop, Cloudflare Pages.
2. Open the HTTPS link in Safari on your iPhone.
3. Tap Start Camera + Mic and allow both permissions.
4. In Safari tap Share > Add to Home Screen.
5. Launch EARA AI from the Home Screen.

Important:
- Camera/microphone access on iPhone requires HTTPS. Opening index.html directly from the Files app will not provide the full camera/mic experience.
- This prototype uses the iPhone rear camera + microphone as the stand-in for the future EARA earpiece.
- iOS may suspend a PWA when it is backgrounded or the phone locks, so this is for concept testing, not yet a true 8-hour background recorder.
- Saved memories/tasks are stored locally in the browser on the phone.
