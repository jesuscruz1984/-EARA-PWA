CORE // AGENT SETTINGS
Agent personality
EARA automatically opens the rear wide-view camera, microphone, Eara wake listening, and speaker when allowed by the browser. Say “Eara” once; she stays active for 10 seconds after the last speech.
Visit Memory: tap Start Visit Memory or say “Eara, start customer visit memory.” While the PWA remains open and the microphone is available, EARA saves the actual visit audio locally in short playable segments, transcribes those saved segments, and builds a local visit transcript. When you stop the visit, EARA analyzes the transcript into a security-estimate recap. In Memory, Play Audio verifies the recording and Analyze Visit retries any missed transcription or analysis. You can then ask “How many cameras did he need?” or “Where did he want them?”
Picture mode: Take Photo captures one 1080p image, visibly flashes, saves it to Picture Memory, analyzes it, and adds the analysis to Memory. “Eara, look at this” does the same.
Document mode: say “Eara, read this paper.” EARA transcribes the full visible page. Show the next page and say “next page.” On the final page say “last page.”
Memory mode: ask EARA to review previous notes or read a saved document back to you.
Noise Filter is enabled by default and asks the browser for microphone noise suppression, echo cancellation, automatic gain control, and mono voice capture when supported.
Important: iPhone can suspend microphone capture when a PWA is locked or fully backgrounded. For a long visit, keep EARA open/foreground. Recording/consent laws vary by location, so use Visit Memory only when any required consent has been obtained.
Text memory, visit transcripts, visit audio, and picture storage are currently stored on this device unless cloud storage is added later.
