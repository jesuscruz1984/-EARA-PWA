CORE // AGENT SETTINGS
Agent personality
EARA automatically opens the rear wide-view camera, microphone, Eara wake listening, and speaker when allowed by the browser. Say “Eara” once; she stays active for 10 seconds after the last speech and keeps that window open while you continue talking.
Document mode: say “Eara, read this paper.” EARA transcribes the full visible page. Show the next page and say “next page.” On the final page say “last page.” EARA will not summarize an incomplete document.
Memory mode: ask EARA to “review our notes and tell me …” to retrieve information, or “go to our memory notes and read me the document” to read the full saved transcription aloud. Say “read the whole thing” or “read that document back to me” for sequential long-form voice playback.
Screen Share switches EARA's live vision from the camera to the shared screen on browsers that support screen capture.
Important: iPhone Safari/PWA currently does not expose browser screen capture. On iPhone, true live screen sharing requires a native EARA app using Apple's screen-capture framework.
Memory is stored on this device and supplied to EARA for recall.
